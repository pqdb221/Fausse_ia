# Fausse_ia
Fausse IA est un chatbot local développé en C++. Il simule une IA grâce à une base de connaissances, la correction de fautes, les synonymes, une mémoire persistante, un système d’XP et l’apprentissage manuel. Il suffit d’écrire le nom de ce que l’on cherche, sans phrase. Aucun modèle d’IA réel n’est utilisé : tout fonctionne en C++.
